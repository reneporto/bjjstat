About

We count. You read the story.

bjj.stat turns official Jiu-Jitsu results into numbers you can share: medal tables, team rankings, records and fun facts.

How we work

  • Official sources only. IBJJF results and registration lists, federation calendars and organiser pages.
  • Counted with code. Every number is computed from the published podiums or lists, then checked twice.
  • Honest wording. If a division had one athlete, we don’t call it a win over anyone. If registrations are still open, we say so.
